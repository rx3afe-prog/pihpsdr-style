# ZPATCHES — локальные доработки piHPSDR

Дата: 03.11.2026. Серия патчей для piHPSDR (fork «novaya»).
Все правки помечены в коде комментариями с именем патча (ZMOVE2, ZAGC, ZAGCW и т.д.).

## ZMOVE2 — dBm Color и Freq Color переехали в Display

- **Что:** кнопки «dBm Color» и «Freq Color» убраны из диалога Panadapter Text
  и добавлены в меню Display как цветные кнопки, рядом с Grid Color и V Grid Color.
  Строки в Panadapter Text перенумерованы, дыр нет.
- **Где:** Display → «dBm Font Color», «Freq Font Color» (под «V Grid Color»).
- **Файлы:** src/display_menu.c (коллбеки pan_dbm_color_set_cb,
  pan_freq_color_set_cb; разметка меню).
- **Цвета:** pan_dbm_color, pan_freq_color — те же переменные, конфиг не менялся,
  ранее выбранные цвета сохраняются.

## ZAGC — цвет и толщина линии АГЦ

- **Что:** линия колена АГЦ (и подпись «-G») получила настраиваемый цвет и толщину.
  Пока цвет не выбран — рисуется как раньше (цвет темы). Линия навески «-H»
  не тронута.
- **Где:** Display → «AGC Color» (цветная кнопка), «AGC Width» (ползунок).
- **Файлы:** src/main.c (переменные), src/radio.c (extern, конфиг),
  src/rx_panadapter.c (рисование), src/display_menu.c (коллбеки, разметка).
- **Ключи конфига:** agc_line_color= (hex, пусто = цвет темы),
  agc_line_width= (0.0 = стандартная толщина).

## ZAGCW — вилка ползунка AGC Width

- **Что:** ползунок AGC Width изменён с 0.0..5.0 на 0.1..2.5 (шаг 0.1).
  Минимум — тонкая линия, максимум — умеренная.
- **Примечание:** если в конфиге было значение больше 2.5, ползунок при запуске
  встанет на максимум; достаточно сдвинуть и значение перезапишется.

## Коммиты

- d60f83d — ZAGC: цвет и толщина линии АГС + вилка width 0.1–2.5
